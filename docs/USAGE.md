# 使用说明

## 余额来源

- **自动选择**：优先使用 Harness 已登录的 DeepSeek 账户；没有登录账户时，使用 Harness 保存的官方 `DEEPSEEK_API_KEY`。
- **已登录账户**：通过 Harness 内置账户服务读取充值钱包和赠送钱包。
- **官方 API Key**：后台仅访问 `https://api.deepseek.com/user/balance`，不接受重定向。

如果账户和 API Key 属于不同账户，请在设置中明确选择来源。当前不查询第三方中转站，也不自动发现自定义名称的凭证。

余额保留服务端精度，界面按两位小数向下截取；不足一分的正余额显示 `<¥0.01` 或 `<$0.01`。币种分别显示，不做汇率换算。

## 峰谷时段

按北京时间，周一至周五 09:00–12:00、14:00–18:00 为波峰，其余时间为波谷。周末（含调休上班的周末）及中国法定节假日全天波谷。

标签只显示峰谷图标和“波峰 / 波谷”，以红、绿色区分。鼠标悬停时显示余额，移开后隐藏。概览右侧展示下次时段切换倒计时。

内置 2026 年节假日表；其他年份无法确定节假日的工作日显示“时段待更新”。官方价格和时段有变化时需要更新插件。

## 消费观测与校正

启用后的余额下降累加为“已观测消费”，余额增加单独列出，并提示待核对。不同账户、API Key 和币种分别建立观测基线，跨北京时间零点重新建立基线。不追溯启用前的数据。

离线、充值同时发生的消费、赠金到期和采样间隔内的变化会影响结果，因此观测消费不能代替官方账单。

在“设置 → 校正今日已观测消费”中输入本日实际累计消费，之后新的余额下降额继续累加。

## 每轮费用与提醒

仅记录插件启用后的本机官方 `deepseek-official` / `deepseek-account` 路由及受支持的 Flash / Pro 模型。使用最终 usage 的输入、缓存与输出 token 计算费用，推理 token 已含在输出中，不重复累加；不包含搜索等按次费用。

开启“每轮结束显示费用提示”后，有新完成轮次时，在窗口左下角、账号栏上方显示临时提示，约 8 秒后消失。摘要每 10 秒查询一次，窗口不可见或连接异常时可能延迟。示例：

```text
最近完成的一轮 · ≈¥0.03 · 12,480 tokens
```

以上金额和 token 数仅为演示。费用也可以在概览与记录页查看。

低余额、每日预算提醒与每轮提示是独立开关；每日预算默认 0，表示关闭。低余额与预算提醒按账户、日期、币种和阈值去重，不申请系统通知权限，不播放声音。

## 记录保留与 CSV

- 每日余额观测：保留 365 天。
- 本机轮次：保留最近 90 天，最多 2,000 轮。
- 记录页：显示最近 7 天观测与最近 10 轮。
- CSV 导出：最近 7 天观测与最近 50 轮；包含会话 ID 等记录信息。

CSV 的余额观测保持原币种，本机费用估算为 CNY。不足一天或未覆盖历史的记录会标注部分数据。

## 已知限制

1. **首条每轮费用提示可能不弹出**：当前客户端会把首次读到的已完成轮次作为初始化基线；如果启用时没有已有轮次，第一条新完成记录也会被用作基线。记录与估算仍会保存，后续完成轮次才触发提示。
2. **短时间多轮完成可能合并提示**：每次查询只拿最近完成的一轮作提醒，多轮在同一查询间隔结束时不会逐一弹出；记录页仍保留各轮数据。
3. **需要可用余额数据**：客户端在获得余额数据后才持续查询记账摘要；尚未登录或凭证不可用时，提示不能保证出现。
4. **价格与节假日需要维护**：当前表于 2026-10-18 核对，仅覆盖相应模型和 2026 年节假日；不能保证后续价格仍准确。
5. **验证范围有限**：已验证 Windows Harness 0.2.1-rc.2；其他桌面版本和操作系统需要重新验证。测试通过不等于所有桌面环境已适配。
