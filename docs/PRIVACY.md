# 数据处理说明

## 网络请求

账户模式通过 Harness 的账户服务查询 DeepSeek。官方 API Key 模式仅向 `https://api.deepseek.com/user/balance` 发送查询请求，禁止 HTTP 重定向。客户端与 Host 通过 Harness 内部连接交换结果。

插件不设置第三方服务器，不发送统计上报。

## 凭证

插件由 Host 向 Harness 凭证服务读取 `DEEPSEEK_API_KEY`，只将其用于官方接口认证。账户模式使用 Harness 自身的登录服务。插件不另存 API Key，也不将登录令牌或 API Key 返回界面或写入账本。

## 本地存储

账本位于 `$DSH_HOME/balance-card/ledger-v1.json`；未配置 `DSH_HOME` 时为 `~/.dsh/balance-card/ledger-v1.json`。

其中包含余额、币种、时间、模型、token 数、会话 ID、轮次与不可逆账户/密钥指纹，不保存对话正文。文件采用串行队列、进程间锁和临时文件原子替换；无法读取的原文件会保留，界面显示存储错误。

刷新设置、显示设置和提醒去重信息保存在当前窗口的本地偏好中。

## 导出与卸载

CSV 由用户点击导出后在本机生成，可能含金额、会话 ID 和模型用量。卸载插件不主动删除账本或导出文件。

提交问题时请使用去除个人信息的截图和样例数据；不要上传凭证文件、登录令牌或真实账本。本仓库预览图中的界面与金额均为演示。
